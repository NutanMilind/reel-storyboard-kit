# Reel Storyboard Kit

**A free, open-source toolkit for planning Instagram Reels, creative storytelling, educational videos, and AI-assisted content production.**

Reel Storyboard Kit helps creators organize their ideas into structured, editable scene-by-scene video storyboards without requiring advanced programming skills.

### Live Application

[Launch Reel Storyboard Kit](https://nutanmilind.github.io/reel-storyboard-kit/)

### Features

- Generate structured Instagram Reel storyboards.
- Plan manifestation, mindset, fashion, and educational content.
- Create scene-by-scene voiceover scripts and visual prompts.
- Customize topics, durations, formats, and calls to action.
- Edit generated storyboard content.
- Download production briefs in Markdown format.
- Use the application directly in a web browser.
- No account or API key required for the storyboard planner.

### Creative Formats

**Universe Chat:** Message-based storytelling with conversational dialogue.

**Whiteboard Explainer:** Educational storytelling using drawings and visual explanations.

**Luminous Cosmos:** Cinematic cosmic and atmospheric visual concepts.

**Paper Cutout:** Layered illustration-based storytelling.

**Minimal Motion:** Motion graphics and typography-focused concepts.

**Product Reveal:** Structured product presentation and fashion content.

### How to Use

1. Open the live application.
2. Choose your content niche.
3. Enter your topic or product.
4. Select a visual storytelling format.
5. Choose your video duration.
6. Click **Generate Storyboard**.
7. Edit the generated scenes, scripts, and visual prompts.
8. Download your Markdown production brief.

### Claude AI Skill

This repository also includes a reusable Claude Skill for short-form video planning.

**Skill location:**

`.claude/skills/reel-storyboard/SKILL.md`

The Skill provides instructions for creating video hooks, voiceovers, timed scenes, visual prompts, and production checklists.

### Current Limitations

This is a video planning tool, not a finished AI video generator.

It does not automatically render MP4 files, generate AI voiceovers, publish Instagram posts, or retrieve live Instagram analytics.

Video production requires separate editing or video-generation software.
